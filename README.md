# ⚡ BedrockBoost — оптимизация Minecraft Bedrock для слабых телефонов

Аддон для **Minecraft Bedrock 1.21.100+** (Android / iOS), который поднимает FPS и помогает с долгой прогрузкой чанков при полёте на элитрах.

## 📥 Скачать

**[⬇ BedrockBoost.mcaddon](https://github.com/Bihan293/Minecraft-bedrock-optimization-mods/releases/latest/download/BedrockBoost.mcaddon)** — один файл, откроется прямо в Minecraft.

Если `.mcaddon` не открывается — скачай отдельно [RP](https://github.com/Bihan293/Minecraft-bedrock-optimization-mods/releases/latest/download/BedrockBoost_RP.mcpack) и [BP](https://github.com/Bihan293/Minecraft-bedrock-optimization-mods/releases/latest/download/BedrockBoost_BP.mcpack).

## ⚠️ Честно о возможностях

В Bedrock **нельзя** сделать настоящий Sodium или Distant Horizons: моды для Bedrock не могут менять движок рендера, только данные (JSON) и скрипты.
BedrockBoost делает всё, что разрешено официально:

| Что | Как помогает |
|---|---|
| **Оптимизация частиц** (192 эффекта, 3 уровня) | Меньше частиц и без расчёта столкновений — минус нагрузка на CPU и GPU. Листопад в лесу в оригинале — до 2000 частиц на дерево! |
| **Pregen — прогрузка мира заранее** | Мир вокруг базы генерируется заранее. Потом при полёте игра только читает готовые чанки, а не генерирует их — они появляются быстрее и без фризов. Это самое близкое к Distant Horizons, что можно сделать в Bedrock |
| **Подгрузка впереди при полёте на элитрах** | Мод ставит зону подгрузки на 3–10 секунд полёта вперёд по курсу, и чанки начинают грузиться заранее |
| **Индикатор на элитрах** | Пишет над хотбаром: «путь прогружен» / «догружается» / «⚠ ВПЕРЕДИ НЕ ПРОГРУЖЕНО», чтобы ты не врезался вслепую |
| **Сканер лагов** | Показывает, сколько мобов, предметов, рамок и стоек вокруг базы, и самые нагруженные чанки с координатами |
| **Очистка предметов** | Вручную или автоматически (с предупреждением за 15 секунд) |
| **Отключение дождя** | Дождь сильно режет FPS на телефоне |
| **Монитор TPS** | Видно, тормозит ли сама игра (TPS) или только графика |
| **Советы по настройкам** | Какие настройки выключить, чтобы получить +FPS |

## 🛠 Установка

1. Скачай `BedrockBoost.mcaddon` и открой его — Minecraft импортирует оба пакета.
2. Мир → **Изменить** → **Наборы ресурсов** → включи **BedrockBoost RP**.
   Нажми ⚙ шестерёнку на паке и выбери уровень:
   - 🟢 **Сбалансированный** — частиц на 40% меньше, всё красиво
   - 🟡 **Макс. FPS** — частиц на 70% меньше, декоративные выключены *(рекомендую для тебя)*
   - 🔴 **Картошка** — почти все частицы выключены
3. **Наборы параметров поведения** → включи **BedrockBoost BP** (RP подключится сам).
4. Зайди в мир. Меню: **`/bb:menu`**, или **присядь и нажми ПКМ (использовать) с палкой в руке**.

> Читы включать **не нужно**. Для Script API в новых версиях никакие «экспериментальные функции» не нужны.

## 🚀 Как избавиться от «слепого полёта» на элитрах

1. Встань на базе → `/bb:menu` → **Прогрузить мир вокруг** → 1000–2000 блоков.
2. Поставь телефон на зарядку и подожди (прогресс видно над хотбаром). Остановить: `/bb:pregen 0`.
3. Летай на высоте **150–200** и не спами фейерверками — на скорости 30–40 блоков/сек чанки успевают прогрузиться.
4. Следи за индикатором над хотбаром.

Команды: `/bb:menu`, `/bb:scan`, `/bb:clean`, `/bb:pregen <радиус>`, `/scriptevent bb:menu`.

## ⚙ Настройки игры, которые дают больше всего FPS

**Настройки → Видео:**
- Дальность прорисовки: **6–8**
- **Моделирование (Simulation distance): 4** — сильно разгружает процессор
- Красивое небо, Красивая листва, Красивые пузыри, Облака, Мягкое освещение — **ВЫКЛ**
- Масштаб рендера / разрешение — **70–80%**
- V-Sync — **ВЫКЛ**, лимит FPS — **30** (стабильнее и телефон меньше греется)
- **Генерация чанков на клиенте — ВКЛ**
- Vibrant Visuals — **ВЫКЛ**

**База:** меньше 15 животных на ферму, меньше рамок, стоек, баннеров; выключай редстоун-часы.

## 👩‍💻 Для разработчиков

```bash
npm install
npm run check                                  # проверка типов Script API
git clone --depth 1 https://github.com/Mojang/bedrock-samples .cache/bs
python3 tools/build_particles.py .cache/bs/resource_pack/particles   # перегенерировать частицы
npm run build                                  # dist/*.mcaddon, *.mcpack
```

Частицы сгенерированы из официальных [Mojang/bedrock-samples](https://github.com/Mojang/bedrock-samples) v1.26.50.
Если после обновления Minecraft пропадут новые эффекты, перегенерируй их скриптом.
